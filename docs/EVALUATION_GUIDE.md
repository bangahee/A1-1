# A1-1 평가 대비 설명 가이드

이 문서는 제출 평가항목을 코드·산출물과 연결하고, 평가 중 질문을 받았을 때 설명할 핵심 답변을 정리한다. 자동 확인은 `python scripts/verify_project.py`로 수행한다.

## 먼저 설명할 이미지 배열 결정

평가항목은 데이터에 수치형·범주형·날짜형·이미지 중 세 종류 이상이 포함될 것을 요구한다. UCI 원본만으로 이미 수치형·범주형·날짜형 세 종류를 충족한다. 별도의 `product_image`는 이미지 Mean/Std를 NumPy 배열 연산으로 계산하는 항목을 재현하기 위해 `stock_code`에서 결정론적으로 생성한 8×8 교육용 배열이다.

이 배열은 실제 사진이라고 주장하지 않으며 시각적 상품 특징으로 해석하지 않는다. 따라서 현재 평가 범위에서는 새 데이터셋으로 교체하지 않는다. 실제 색상·형태 같은 시각 정보가 필요한 후속 분석에서는 공개 라이선스 상품 이미지를 상품 코드와 연결해 동일한 파이프라인에 입력해야 한다.

### 3. 데이터 크기와 유형

- 크기: 25,000행 × 14열
- 수치형: `quantity`, `unit_price`, `amount`, `customer_id` 등
- 범주형: `stock_code`, `description`, `country`
- 날짜형: `order_date`
- 배열형: 파싱 후 NumPy 배열이 되는 `product_image`

### 5. 이상치 전후 비교

`figures/02_outlier_boxplot.png`가 원본 `amount`와 IQR 클리핑 후 `amount_clean`을 비교한다. 양수 구매 이상치는 1,925건에서 0건으로 감소하며 그림 안에 건수와 비율이 표시된다.

### 6. 여섯 종류 시각화

`figures/01`부터 `06`까지 히스토그램, 박스플롯, 막대그래프, 히트맵, 산점도, 라인차트가 있다. 제목과 양 축 레이블은 코드와 `outputs/visualization_evidence.csv`, `figures/CAPTIONS.md`에서 교차 확인할 수 있다.

### 7. 기술통계와 상관분석

`quantity`, `unit_price`, `amount`에 평균·중앙값·표준편차·사분위수 해석이 있다. Frequency–Monetary 상관은 약 0.79로 양의 관계이고, Recency–RFM_score는 약 -0.69다. 전자는 주문 횟수가 많은 고객의 누적 구매금액도 큰 경향을 뜻하지만 인과관계는 아니다. 후자는 최근 구매일이 오래될수록 점수가 낮아지는 점수 설계가 반영된 결과다.

### 8. RFM 그룹과 비즈니스 인사이트

고객 3,251명을 `VIP`, `Loyal`, `New`, `Churned` 네 그룹으로 분류한다. README의 세 제안은 각각 정확한 `(근거)`, `(실행)`, `(검증)` 구조를 사용하며 실패 조건이나 추가 데이터를 명시한다.

## 항목 2 — 코드 설계 설명

### 1. 메서드를 분리한 이유

- `load_data()`: 파일·스키마·타입이라는 입력 경계를 책임진다.
- `handle_missing_values()`: 결측 정책만 책임져 대치 전략을 교체하기 쉽게 한다.
- `engineer_features()`: 정제된 데이터에서 파생 변수를 만드는 책임을 갖는다.
- `detect_outliers()`와 `treat_outliers()`: 탐지와 변경을 분리해 탐지만 하거나 clip/remove를 선택할 수 있다.
- `calculate_rfm()`: 거래 행을 고객 단위 결과로 바꾸는 집계 책임을 갖는다.

책임을 나누면 각 단계를 독립적으로 테스트할 수 있고 다른 데이터셋에서는 필요한 단계만 재사용하거나 교체할 수 있다.

### 2. 이미지 피처를 벡터화한 이유

`np.stack(frame["product_image"].to_numpy())`로 2차원 연속 배열을 만든 다음 `mean(axis=1)`과 `std(axis=1)`을 호출한다. Python for문처럼 행마다 인터프리터를 호출하지 않고 NumPy의 컴파일된 루프가 한 번에 동일 연산을 수행하므로 빠르다.

### 3. 주요 값을 인자로 만든 이유

- `outlier_threshold`: B2C와 B2B처럼 정상 고액 주문의 수준이 다른 환경에서 1.5 또는 3.0 등을 선택할 수 있다.
- 결측 전략과 그룹 열: 상품 코드가 아닌 다른 기준으로 대치하거나 정책을 바꿀 수 있다.
- `reference_date`: 데이터 재실행 날짜에 따라 Recency가 달라지는 것을 막고 특정 캠페인 기준일을 재현한다.
- `min_rows`, `min_columns`: 과제와 운영 데이터 계약의 최소 규모를 환경별로 바꾼다.

### 4. 노트북 의사결정 문서화

노트북의 마크다운은 데이터 출처, 결측 대치 이유, 이미지 배열의 범위, IQR 선택과 한계, RFM 사분위 선택, 상관관계 해석, 비즈니스 검증 조건을 분석 순서대로 설명한다.

## 항목 3 — 원리 이해

### 1. IQR 필요성·적합한 분포·한계

IQR은 `Q1 - 1.5×IQR`보다 작거나 `Q3 + 1.5×IQR`보다 큰 값을 표시한다. 중앙 50%를 사용해 정규분포를 가정하지 않고 극단값 자체의 영향도 작으므로 오른쪽 꼬리가 긴 구매금액에 적합하다. 그러나 실제로 정상인 대량 주문도 이상치로 잡을 수 있고, 서로 다른 상품·고객 그룹의 분포 차이를 무시한다. 코드는 `outlier_bounds()`, `detect_outliers()`, `treat_outliers()`에 있다.

### 2. 그룹별 대치 이유와 위험

`description`은 숫자 평균이 정의되지 않는 범주형 값이라 같은 `stock_code` 안의 최빈값을 사용한다. 전역 최빈값보다 상품 정체성을 보존하고 행 삭제보다 정보 손실이 작다. 다만 관측값을 반복하므로 그룹 내부 다양성과 분산이 줄고 그룹 간 차이가 실제보다 커 보일 수 있다. 운영에서는 대치 플래그와 상품 마스터를 함께 사용해야 한다.

### 3. RFM 기준과 실제 타당성

사전 비즈니스 임계값이 없으므로 순위 기반 4분위를 사용한다. 4분위는 각 구간에 충분한 고객을 유지하면서 네 운영 세그먼트에 연결하기 쉬운 절충안이다. 현재 결과에서 VIP 27.8%가 조정 매출 63.4%를 만들고, Churned 50.0%의 평균 Recency는 179.5일이므로 세그먼트가 행동과 가치 차이를 실제 수치로 구분한다. 운영 전에는 30/90/180일과 주문 횟수·LTV 임계값으로 민감도를 비교해야 한다.

### 4. NumPy가 빠른 이유

NumPy 배열은 같은 자료형을 연속 메모리에 배치한다. CPU가 캐시를 효율적으로 사용하고 여러 값을 한 명령으로 처리하는 SIMD에 유리하다. 또한 반복이 C로 컴파일된 내부 루프에서 실행돼 Python 객체 조회와 동적 타입 검사 비용을 행마다 지불하지 않는다.

## 항목 4 — 확장 사고

### 1. 고객 100만 명과 1024×1024 이미지

회색조 `uint8` 이미지도 100만 장이면 약 0.95 TiB이고, `float32`로 한꺼번에 쌓으면 약 3.81 TiB다. 따라서 저장소·네트워크 I/O와 디코딩, RAM이 먼저 병목이 되며 전체 `np.stack()`은 불가능하다.

개선 순서는 다음과 같다.

1. 원본 이미지는 객체 저장소에 두고 표에는 경로와 사전 계산 특징만 저장한다.
2. CSV 문자열 대신 압축 이미지와 Parquet/NumPy 바이너리 같은 형식을 사용한다.
3. 이미지를 배치 단위로 읽고 `uint8`을 유지하며 필요한 순간에만 `float32`로 변환한다.
4. 분석 목적에 맞게 다운샘플링하거나 층화 표본을 먼저 사용한다.
5. Mean/Std처럼 반복 사용되는 특징은 한 번 계산해 저장한다.
6. 프로파일링 후 I/O 병렬화와 분산 처리를 적용하되 여러 프로세스의 전체 데이터 복사를 피한다.

### 2. 마케팅 우선순위

첫 우선순위는 VIP 유지다. 고객 27.8%가 조정 매출 63.4%를 만들기 때문에 작은 대상에서 매출 방어 효과가 크다. 리스크는 혜택 비용, 기존 자연 재구매 고객에게 지급하는 불필요한 보조금, 특정 고객군 매출 집중이다. 90일 무작위 대조군의 반복구매율·이탈률·증분 공헌이익으로 검증한다. 이후 Churned 재활성화와 New의 2회차 전환을 각각 별도 대조 실험으로 진행한다.

### 3. 머신러닝 확장

권장 타깃은 기준일 이후 90일간 구매가 없으면 1인 `churn_90d`다. 입력 피처는 기준일 이전의 Recency, Frequency, Monetary, 평균 주문금액, 반품률, 고유 상품 수, 활동 개월 수, 국가, 최근 30/60/90일 주문 횟수·금액, 결측 대치 플래그다. 타깃 기간의 주문·금액과 사후 세그먼트는 데이터 누수이므로 제외한다. 시간순 분할을 사용하고 Accuracy보다 Recall, Precision, PR-AUC, 확률 보정과 캠페인 기대가치를 평가한다.
