# 분석 방법을 설명하는 순서

분석 선택과 결과를 본인의 말로 설명하기 위한 안내다. 수치는 README 또는 현재 산출물에서 확인하며, 파일과 메서드를 직접 열어 입력·출력·한계를 함께 살펴본다.

| 설명 주제 | 확인 위치 | 설명할 내용 |
|---|---|---|
| 입력과 데이터 유형 | data/DATASET.md, 노트북 기본 탐색 | 규모, 자료형, 출처, 거래 표본의 범위 |
| 단계별 책임 | src/pipeline.py | 로드·결측·특징·탐지·집계·요약을 분리한 이유 |
| 인자와 재사용 | DataAnalyzer 생성자와 공개 메서드 | 임계값·전략·그룹·기준일·점수 구간을 바꾸는 예 |
| 결측 처리 | handle_missing_values(), 교육용 대치 표 | 문자열 최빈값과 수치 평균·중앙값의 차이, 대치 위험 |
| 배열 특징 | engineer_features() | stack, axis=1, 연속 메모리, 캐시, 컴파일 루프, SIMD 조건 |
| IQR | outlier_bounds(), 전후 박스플롯 | 중앙 50% 기반 경계, 긴 꼬리·다봉·그룹 차이의 한계 |
| 두 쌍의 상관 | 노트북과 rfm_correlations.csv | 계수의 방향·강도·시사점과 인과 해석 한계 |
| 고객군 타당성 | rfm_score_ranges.csv, 그룹 통계, 민감도 | 실제 경계와 분포, 동점 보존, 기준 변경에 따른 이동 |
| 마케팅 | README의 비즈니스 제안 | 대상·방법·기대 효과·대조군·비용·실패 조건 |
| 대규모 확장 | scaling_estimates.csv | 이미지 수와 형식 가정, RAM·입출력, 캐시·배치 개선 |
| 머신러닝 확장 | README와 METHODOLOGY.md | 관측 시점·미래 90일·우측 검열·현재/후보 피처·누수 |

설명 예시를 준비할 때는 선택 이유만 나열하지 않고 코드 위치, 실제 수치, 대안과 한계를 연결한다. `New`를 신규 가입자로, `Churned`를 확정 이탈자로 설명하지 않는다. 통계상의 상관이나 상대 분류만으로 캠페인의 인과 효과를 주장하지 않는다.

현재 테스트·노트북 실행 결과는 실행 기록에서 확인한다. 설명 자료가 있다는 사실과 직접 원리를 이해하고 설명할 수 있다는 것은 구분한다.
