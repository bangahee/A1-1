# 이미지 배열 설계 선택 근거

## 설계 결정

본 프로젝트는 실제 상품 이미지 데이터셋으로 교체하지 않고 UCI Machine Learning Repository의 **Online Retail 거래 데이터**를 분석 대상으로 유지했다. 이미지 관련 구현에는 상품 코드(`stock_code`)로부터 결정론적으로 생성한 8×8 숫자 배열을 사용했다.

이 선택은 프로젝트의 핵심 분석 목적이 상품의 시각적 특성 분석이 아니라 **실제 거래 기록을 이용한 전처리, 파생 변수 생성, RFM 고객 세분화와 비즈니스 인사이트 도출**에 있기 때문이다.

## 데이터셋 선택 근거

RFM 분석을 수행하려면 고객, 거래 시점, 주문과 금액을 식별할 수 있는 정보가 함께 존재해야 한다. Online Retail 데이터는 다음 핵심 필드를 제공한다.

| 분석 요소 | 사용 필드 |
|---|---|
| 고객 식별 | `customer_id` |
| 최근 구매일 | `order_date` |
| 구매 빈도 | `invoice_no` |
| 구매 금액 | `quantity`, `unit_price` |
| 상품 정보 | `stock_code`, `description` |

또한 결측 고객 ID와 상품 설명, 반품 및 취소, 음수 수량, 편향된 거래 금액과 반복 구매가 포함되어 있어 실제 데이터 전처리 판단을 보여주기에 적합하다. 원본 데이터는 수치형, 범주형·텍스트형, 날짜형의 세 가지 실제 데이터 유형을 이미 포함한다.

실제 이미지가 포함된 별도의 상품 데이터셋으로 교체할 경우 이미지 정보는 확보할 수 있지만, 고객 ID·주문번호·거래일·반복 구매 이력이 함께 제공되지 않으면 RFM 분석의 근거가 사라진다. 따라서 실제 이미지의 존재보다 거래 분석에 필요한 데이터 구조와 분석 목표의 일관성을 우선했다.

## 이미지 배열을 포함한 이유

원본 Online Retail 데이터에는 상품 사진이나 이미지 URL이 없다. 그러나 본 프로젝트에서는 배열형 데이터의 로드와 검증, NumPy 기반의 벡터 연산, Mean/Std 파생 피처 생성을 구현할 필요가 있었다.

이를 위해 `stock_code`를 안정적으로 해시하여 각 상품에 대응하는 64개 값의 배열을 생성했다. 같은 상품 코드는 항상 같은 배열을 가지며, 고정된 표본과 함께 동일한 결과를 재현할 수 있다. 이 배열은 다음 기술 구현을 위한 입력으로만 사용한다.

- CSV에 저장된 배열 문자열의 NumPy 배열 복구
- 배열 길이, 빈 배열, NaN과 무한대 값 검증
- `np.stack()`을 이용한 2차원 행렬 구성
- `mean(axis=1)`과 `std(axis=1)`을 이용한 벡터 피처 생성
- Python 행별 반복을 대체하는 NumPy 벡터 연산

따라서 `product_image`라는 열 이름은 이미지 형태의 배열 처리 흐름을 나타내지만, 그 값은 실제 상품 사진에서 추출한 픽셀이 아니라 **재현 가능한 교육용 배열**이다.

## 분석 적용 범위

교육용 배열에서 생성한 `image_mean`과 `image_std`는 배열 처리 파이프라인의 동작을 검증하는 데만 사용했다. 실제 상품의 색상, 형태, 질감, 촬영 밝기 또는 품질을 나타내는 변수로 해석하지 않았다.

다음 결과는 교육용 배열과 독립적으로 실제 거래 필드만을 사용해 산출했다.

- Recency, Frequency, Monetary
- RFM 점수와 고객 세그먼트
- 거래 금액과 월별 매출 분석
- 고객군별 비즈니스 인사이트
- 마케팅 우선순위와 검증 제안

이와 같은 분리를 통해 교육용 배열이 고객 가치나 매출 결과에 영향을 주거나, 실제 시각 정보가 존재하는 것처럼 결과를 과장하지 않도록 했다.

## 선택의 타당성

현재 설계는 두 목적을 분리하여 충족한다.

1. 실제 거래 데이터를 기반으로 신뢰 가능한 RFM 분석을 수행한다.
2. 별도의 교육용 배열을 통해 배열 파싱, 검증과 NumPy Mean/Std 벡터 연산을 재현한다.

실제 이미지가 없는 점을 감추지 않고 데이터 생성 방식과 사용 범위를 명시했으며, 배열에서 얻은 수치를 비즈니스 해석에 사용하지 않았다. 따라서 프로젝트의 분석 결론은 실제 거래 데이터에 근거하고, 이미지 배열은 기술 구현의 범위로 제한된다.

## 한계와 향후 확장

현재 설계는 실제 상품 사진을 로드하거나 상품의 시각적 특성을 분석하지 않는다. 이미지 기반 분류, 색상·형태 분석 또는 시각적 특성과 구매 행동의 관계를 연구하려면 공개 라이선스 상품 이미지를 확보하고 상품 식별자와 연결해야 한다.

향후 실제 이미지로 확장할 때는 다음 사항이 추가로 필요하다.

- 이미지 출처와 라이선스 기록
- 이미지와 `stock_code` 또는 별도 상품 ID의 정확한 연결
- 크기와 색상 채널의 표준화
- 손상 이미지와 결측 이미지 처리 정책
- 대규모 데이터의 배치 처리, 다운샘플링과 사전 피처 계산

실제 이미지가 연결되면 현재의 배열 검증 및 NumPy 피처 생성 구조를 그대로 확장할 수 있다. 단, 실제 시각 정보가 분석 목표가 되는 시점에는 단순 Mean/Std뿐 아니라 목적에 맞는 이미지 피처와 검증 방법을 추가해야 한다.

## 최종 입장

본 프로젝트에서는 실제 이미지의 유무보다 RFM 분석에 필요한 거래 데이터의 완전성과 분석 목표와의 적합성을 우선했다. 이에 따라 Online Retail 데이터를 유지하고, 이미지 관련 요구는 출처와 한계가 명확한 교육용 배열로 분리해 구현했다.

현재 결과는 **실제 상품 이미지 분석 결과가 아니라 실제 거래 데이터 분석과 이미지 형태 배열 처리의 결합**으로 정의한다. 실제 시각적 의미를 주장하지 않는 범위에서 이 설계는 재현성, 분석 타당성 및 구현 목적을 함께 보존한다.
