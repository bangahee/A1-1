# 교육용 배열의 생성과 적용 범위

Online Retail은 고객·주문·날짜·수량·단가·상품 설명을 제공해 거래와 고객 행동을 분석하기 적합하지만 상품 사진이나 이미지 URL은 포함하지 않는다.

현재 `product_image`는 `stock_code`의 안정적인 해시와 픽셀 위치를 브로드캐스팅해 만든 64개 정수 값이다. 같은 상품 코드에는 같은 8×8 배열이 생성된다. CSV 문자열을 `np.fromstring()`으로 복원하고 `np.stack()`으로 쌓아 평균·표준편차를 계산한다. `figures/08_educational_array.png`는 이 값의 배열 형태를 보여준다.

이 입력은 실제 상품의 색상·형태·질감이나 사진 밝기를 뜻하지 않는다. 배열 파싱·유효성 검사·벡터 연산을 재현하는 교육용 자료이며 거래 집계와 RFM에는 이 배열 피처를 사용하지 않는다. 수치형·범주형·날짜형은 별도의 실제 거래 필드에서 확보한다.

교육용 배열이 상품 이미지 요구에서 인정되는지는 적용되는 데이터 기준에 따라 확인해야 한다. 배열 연산이 구현됐다는 사실만으로 실제 상품 이미지 분석을 수행했다고 표현하지 않는다.

실제 이미지 분석으로 확장할 때 필요한 것은 다음과 같다.

- 이미지의 출처·공개 라이선스와 상품 ID의 실제 대응 관계
- 높이·너비·채널 및 유효값의 검증
- 허용된 입력 함수로 읽은 NumPy 배열과 슬라이싱 다운샘플링
- 손상·결측 이미지의 명시적 정책
- 고유 상품 단위 피처 캐시와 배치 처리

관련 없는 사진을 임의로 상품 코드에 연결하지 않는다. 실제 사진이 필요하다는 기준이 명확해지면 이 입력을 교체하고, 동일한 NumPy 특징 구조에서 결과를 다시 계산한다.
